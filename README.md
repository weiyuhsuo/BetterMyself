# BetterMyself / 会更好

一个原生 iOS SwiftUI MVP，用来验证“打开、输入、收起来、回看”的私密碎片记录体验。

## 运行

1. 安装 Xcode。
2. 打开 `BetterMyself.xcodeproj`。
3. 选择 iOS 17+ 模拟器或已连接的 iPhone。
4. 点击 Run。

如果命令行仍指向 Command Line Tools，可以在 Xcode 安装后运行：

```sh
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
```

## 当前范围

- SwiftUI 原生界面。
- SwiftData 本机保存。
- 输入页默认作为启动体验。
- 回看页按日期分组、倒序展示。
- 详情页查看完整内容。

首版不包含账号、云同步、AI、心情选择、标签、图片、语音或统计。
